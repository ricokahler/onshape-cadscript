# Print Tolerances

<!--@include: ../snippets/tolerance-coupon.md-->

Start with a short coupon, not a full product. Keep clearances in named parameters and log printer, material, nozzle, layer height, orientation, and measured result.

Typical first trials per side:

| Fit          |        Clearance |
| ------------ | ---------------: |
| Sliding rail |     0.20-0.35 mm |
| Snug pocket  |     0.15-0.25 mm |
| Free hinge   |     0.30-0.50 mm |
| Press fit    | 0.00 to -0.15 mm |

These are starting points, not universal dimensions.
