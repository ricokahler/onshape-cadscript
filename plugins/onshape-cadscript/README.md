# Onshape CadScript for Codex

This npm package is the installable Codex plugin for [Onshape CadScript](https://github.com/ricokahler/onshape-cadscript). Install it through the repository marketplace so Codex can resolve the matching SDK/MCP version.

```sh
codex plugin marketplace add ricokahler/onshape-cadscript --sparse .agents/plugins
codex plugin add onshape-cadscript@onshape-cadscript
```

Unofficial community software. Not affiliated with or endorsed by Onshape or PTC.
