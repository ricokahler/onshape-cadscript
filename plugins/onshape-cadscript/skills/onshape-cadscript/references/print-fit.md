# Print-Fit Recipes

Treat clearances as named parameters and tune them from test prints.

| Fit               | Starting per-side clearance | Notes                                                      |
| ----------------- | --------------------------: | ---------------------------------------------------------- |
| Sliding rail      |                0.20-0.35 mm | Print a short coupon before the full part.                 |
| Snug pocket       |                0.15-0.25 mm | Increase for textured or elephant-foot-prone first layers. |
| Free-moving hinge |                0.30-0.50 mm | Orientation and support scars matter.                      |
| Press fit         |            0.00 to -0.15 mm | Material, wall thickness, and grain direction dominate.    |

These are starting points, not universal specifications. Record printer, material, nozzle, layer height, orientation, measured result, and the next parameter change.
